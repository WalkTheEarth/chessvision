# Assets

`boards/` and `pieces/` come from
[GiorgioMegrelli/chess.com-boards-and-pieces](https://github.com/GiorgioMegrelli/chess.com-boards-and-pieces)
(branch `v2.x`), which collects chess.com board and piece images. They are used here
only to build recognition templates and to render the synthetic self-test images.

`--pieces NAME` picks a folder from `pieces/`; `--board NAME` picks a PNG from
`boards/`.
